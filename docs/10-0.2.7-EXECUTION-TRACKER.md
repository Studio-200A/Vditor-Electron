## 最终实现与职责

### 文档反馈和链接错误

- `documents/document-feedback.ts` 的 `DocumentFeedback` 负责打开失败、保存/重载/忽略/重建结果的三语文案与状态栏/通知映射；保存交易和文档状态仍由原控制器拥有，组合层只注入窄依赖。
- 主动操作失败（链接、打开/保存、图片、文件拖入、标签上限）使用短暂通知；普通成功反馈仍使用状态栏。重建结果保留通知回调，常驻恢复、外部冲突与文件不可用警示保持安全动作入口。
- `DocumentLinkNavigationController` 统一分类相对 Markdown、扩展名不支持、绝对路径和 `file:` 链接。后三类在悬停和 Ctrl/Cmd+点击时使用各自原因，并保持文本光标；支持链接按 modifier 显示手型和跳转提示，普通点击保留编辑行为。
- 复用 adapter 的语义 hint/cursor API 和 title 恢复，不新增私有 Vditor DOM 访问；移出链接或窗口失焦清理 hover。
- main/renderer 共用 `shared/contracts/markdown-link.d.ts` 的 typed result。缺失文件与非普通文件按领域结果返回，权限/I/O 异常保留并经安全 IPC 分类，不能一律报目标不存在。
- `main/open-files.ts` 保留外部请求中的缺失或不可访问 Markdown 路径，让既有打开流程报告错误；继续忽略已存在目录、非 Markdown、flags、无效 file URL 和不支持的 URL scheme。

### 顶部横幅与短暂通知队列

- `index.html` 的 `.document-banner-stack` 将恢复、外部冲突、文件不可用与短暂通知按实际高度纵向排列，间距 8px；短暂提示位于常驻警示下方，没有常驻警示时位于编辑区顶部。
- `NotificationsController.showNotice()` 创建独立条目：最新在上，每条独立计时 5 秒，重复点击也创建新提示。最多 3 条活动提示，第 4 条出现时最旧条目取消寿命计时并立即渐隐。
- 四类横幅统一 180ms 透明度过渡；渐隐结束才移出布局，退出中的通知可以短暂与新条目共存。系统减少动态效果时立即切换。
- 错误提示使用 warning.svg、主题 danger 配色和 role=alert；渐隐期间保留颜色和图标。容器与短暂提示允许鼠标穿透，常驻横幅保留按钮交互，隐藏/退出时禁用交互。
- 退出通知经 opacity transitionend 清理；没有启动过渡时由 250ms fallback 清理。dispose 释放寿命/退出计时器、监听与对话框资源。
- `#temporaryDocumentNotice` / `#temporaryDocumentNoticeMessage` 始终指向最新条目，旧条目移除对应 ID；最新条目退出后保留隐藏插入点，供下一条替换。状态栏消息不清除通知，也不改变焦点。

### 文件拖入

- `AppController` 在 body 捕获阶段分类文件，避免 Vditor 3.11.3 先把 TXT 当作图片上传。
- Markdown 交给既有文档打开命令，混合文件中保留 Markdown 打开行为；编辑区内纯图片继续走 Vditor 上传，其他文件先阻止传播并显示三语拖入提示。
- 未保存文档拖入 TXT 显示“仅支持拖入 Markdown 文件”；图片仍显示保存前置条件。文字与 HTML 拖放不进入文件分类，listener 随 controller dispose 清理。

### 标签溢出

- `#tabBar` 为外层布局，`.tab-scroll-region` 内的 `#tabStrip` 独立横向滚动；`#addTab` 与可拖动空白位于滚动区之外，新建按钮始终可见。
- 保留既有标签宽度、滚轮、中键关闭、拖动排序和活动标签自动滚入视野，不引入浏览器式全标签宽度压缩。
- 左右 14px 阴影覆盖层仅在相应方向仍有隐藏标签时显示，到达尽头或没有溢出时消失；阴影取主题 sidebar-surface 混合暗部，允许鼠标穿透，不新增箭头。
- `TabController` 拥有 scroll/wheel listener、ResizeObserver 和溢出状态；render、滚动、尺寸变化时更新，dispose 清理。组合层移除旧滚轮函数和标签栏 auto-hide scrollbar 接线。

## 手测反馈与已修正的验证缺口

1. 首轮错误提示测试将既有英文 Could not open 写成 Unable to open，修正断言后通过。
2. 用户首轮全量测试报告 document-lifecycle.spec.ts 的并发 Save As 别名用例失败：应用已把 path-open 反馈迁到通知，测试仍等 statusMessage。更新通知断言，保留路径、落盘和 dirty 安全断言，重复复验通过；最终全量 gate 通过。
3. 真实第二实例缺失文件没有横幅：旧 argv parser 因 stat 失败丢弃请求。原测试直接发送 renderer 事件，未覆盖入口；修正 parser，并用 openFromSecondInstance() 真实第二进程替换模拟事件。先前的系统聚焦通知不能证明文件打开结果。
4. 首轮底部避让不符合手测预期：改为顶部实际高度排列，并加入统一过渡和最多三条的通知队列。
5. TXT 拖入被误当作未保存图片：捕获分类修正。首轮 IR/WYSIWYG 回归测试误向外层投递图片事件，改为实际可编辑节点后通过。
6. 标签栏旧壳层测试要求已迁出的 scrollbar selector，改为新建按钮位于滚动区外的 DOM 契约。新主题测试曾误将具体主题 ID 当作 light/dark 模式，改用实际主题 CSS；尺寸验证显式关闭默认最大化，避免 setSize 被窗口状态掩盖。
