# 0.2.5 版本工具栏改进专项

## 1. 专项目标

统一工具栏、侧边栏和标题栏在不同布局状态下的视觉归属与交互预期，消除“隐藏工具栏后仍残留半段工具栏”的割裂感。

本专项定义用户可见的交互和验收结果，不限定具体模块、函数、DOM 结构、状态承载方式或动画实现。实施时应适配完成模块化重构后的渲染层职责边界。

## 2. 当前问题

当前 Files / Outline 视图切换与编辑器工具栏在视觉上共同构成一行工具栏。

当用户在主菜单的“布局”中隐藏工具栏时，编辑器格式工具栏会隐藏，但侧边栏的 Files / Outline 仍停留在原工具栏位置。此时视觉上只隐藏了工具栏的一部分，容易造成布局状态不完整、层级不清晰的感受。

此外，若标题栏跟随侧边栏显隐动画横向移动，标题栏下方投影需要随之进行复杂适配。该方式难以同时保证投影连续、窗口拖拽区域可用、菜单和窗口控制按钮可操作，因此不再作为本专项的实现方向。

## 3. 设计原则

1. 标题栏是稳定的窗口 chrome，不随侧边栏显隐及其动画横向移动。
2. 新建、打开、保存是基础文件操作，始终位于标题栏中，不因侧边栏显隐而隐藏、缩小或失去交互能力。
3. Files / Outline 的位置由“编辑器工具栏是否显示”决定：显示工具栏时保持当前视觉；隐藏工具栏时归属侧边栏内容区域。
4. 隐藏工具栏应隐藏完整的视觉工具栏，而不是仅隐藏编辑器格式操作的一部分。
5. 视觉调整不得牺牲标题栏的窗口控制、菜单、拖拽、键盘操作、焦点可见性或现有编辑行为。

## 4. 目标交互与视觉表现

### 4.1 标题栏

- 标题栏在侧边栏显示、隐藏及过渡动画期间保持整体位置和尺寸稳定。
- 新建、打开、保存三个操作始终显示在标题栏内；侧边栏收起、展开或动画过程中仍可点击和键盘聚焦。
- 保存操作原有的可用与禁用语义保持不变。例如没有可保存文档时，保存按钮仍应保持禁用状态，而不是仅维持视觉可见。
- 标题栏下方应始终形成稳定、连续的内容分隔与投影效果（投影视觉效果匹配当前toolbar向下方区域的投影效果），不跟随侧边栏宽度或显隐动画横向变化。
- 投影不得覆盖、阻断或降低菜单、基础文件操作、窗口控制按钮及窗口拖拽区域的可用性。

### 4.2 显示工具栏

当编辑器工具栏显示时，Files / Outline 保持当前的布局、位置、视觉样式和交互方式。

它继续与编辑器工具栏在视觉上组成一行顶部工具栏；本专项不改变这一状态下的既有体验。

### 4.3 隐藏工具栏且侧边栏显示

当用户隐藏编辑器工具栏、且侧边栏处于显示状态时：

- 编辑器格式工具栏完整隐藏。
- Files / Outline 不再停留在顶部工具栏位置。
- Files / Outline 下沉到侧边栏内容区域，位于侧边栏内容的顶部、工作区信息与文件树或大纲内容之前。
- Files / Outline 在此状态下表现为侧边栏视图导航，而不是残留的工具栏部分。
- 其视觉为文本式 tab：不采用突出的实体按钮外观；鼠标悬停时显示可交互反馈，当前选中项具有清晰的选中反馈。
- 文本不可被选择，鼠标悬停时使用指针光标。
- 保留原生可访问交互：可通过键盘聚焦和激活，焦点状态清晰可见，辅助技术可识别其名称、当前选中状态和操作目的。
- Files / Outline 的当前选中视图在隐藏或重新显示工具栏后保持不变。

目标示意：

```plaintext
Files | Outline
<工作区目录名>
文件树或大纲内容
```

### 4.4 隐藏工具栏且侧边栏隐藏

当编辑器工具栏与侧边栏均隐藏时：

- 编辑器格式工具栏不显示。
- Files / Outline 不显示。
- 页面保留稳定的标题栏和编辑区域，不出现残留的侧栏导航、空白工具栏区域或不连续的分隔效果。

## 5. 状态矩阵

| 编辑器工具栏 | 侧边栏 | Files / Outline            | 标题栏文件操作 | 标题栏投影 |
| ------------ | ------ | -------------------------- | -------------- | ---------- |
| 显示         | 显示   | 保持顶部工具栏中的当前表现 | 常驻、可操作   | 稳定       |
| 显示         | 隐藏   | 随侧边栏不可见             | 常驻、可操作   | 稳定       |
| 隐藏         | 显示   | 下沉为侧边栏内容区导航     | 常驻、可操作   | 稳定       |
| 隐藏         | 隐藏   | 不显示                     | 常驻、可操作   | 稳定       |

## 6. 非回归边界

- 不改变 Markdown 文件格式、文件读写、工作区、设置持久化或跨进程安全边界。
- 不重建编辑器实例，不影响编辑模式、内容、选区、撤销/重做、编辑器工具栏项目或编辑器已有的状态恢复行为。
- 不改变 Files / Outline 的切换能力、文件树与大纲内容、打开工作区后默认显示 Files 的既有行为。
- 不改变窗口控制、窗口拖拽、应用菜单、快捷键和全屏的既有职责。
- 不新增未本地化的用户可见文字。
- 不要求通过标题栏跟随侧边栏移动、在窗口可视区域外扩展标题栏，或叠加影响标题栏交互的复杂视觉层来实现效果。

## 7. 验收标准

### 7.1 基础状态

1. 显示工具栏时，Files / Outline 与当前版本的顶部工具栏视觉和交互一致。
2. 隐藏工具栏且侧边栏显示时，顶部不再出现 Files / Outline；它们显示在侧边栏内容顶部并可正常切换文件树和大纲。
3. 隐藏工具栏且侧边栏隐藏时，Files / Outline 不可见，编辑区紧接稳定标题栏显示。
4. 在任意工具栏和侧边栏组合下，新建、打开、保存均保持标题栏可见性；其既有启用、禁用和操作结果不变。
5. 切换工具栏可见性前后，Files / Outline 当前选中视图保持不变。

### 7.2 动画与窗口交互

1. 侧边栏展开、收起、快速反向切换及关闭动效偏好开启时，标题栏整体不发生横向跟随移动。
2. 侧边栏动画期间，新建、打开、保存、菜单、窗口控制和窗口拖拽均持续可用。
3. 标题栏下方分隔与投影在侧边栏显示、隐藏和过渡期间保持连续，不出现跳动、断裂、遮挡或明显闪烁。
4. 侧边栏动画完成后，编辑区域、标签区与编辑器工具栏（显示时）的布局正确，无残留偏移或空白。

### 7.3 布局与可访问性

1. 在正常窗口、最大化、全屏及全屏菜单显示状态下，四种工具栏/侧边栏组合均符合本专项定义。
2. 在窄窗口和调整侧边栏宽度后，标题栏基础文件操作不重叠、不被裁切，并保持可操作。
3. 下沉状态的 Files / Outline 文本不可选择，鼠标悬停为指针，hover、选中和键盘焦点状态均可辨识。
4. 所有新增或变化的用户可见文本在 English、简体中文和繁体中文下均正确显示；如不新增文案，不得引入硬编码文本。

### 7.4 持久化与验证

1. 用户设置的工具栏与侧边栏可见性在重启后保持既有持久化行为。
2. 切换布局后不影响编辑器内容、未保存状态、文件树、文档大纲和标签页状态。
3. 自动化验证应覆盖状态矩阵、Files / Outline 切换、标题栏基础文件操作、侧边栏动画和关键窗口状态；实现完成后按项目发布前检查要求执行完整回归。

## 8. 实施范围

本专项仅调整应用壳层的布局、交互和视觉表现。具体技术设计应在模块化重构完成后，基于当时的最终模块职责、状态模型和测试结构另行确定并维护。
